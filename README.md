# Hemotrack

Sistema web para gerenciamento de bancos de sangue, desenvolvido em equipe durante o programa Web Academy. O projeto tem como objetivo centralizar informações sobre doadores, bolsas de sangue e estoques, facilitando o acompanhamento das movimentações e a identificação de situações que exigem atenção.

## Sobre o projeto

O gerenciamento de estoques de sangue exige acompanhamento constante da disponibilidade e da validade das bolsas. A falta de informações centralizadas e de mecanismos de monitoramento pode dificultar a tomada de decisões e contribuir para situações de escassez ou desperdício.

O Hemotrack foi concebido para apoiar esse processo por meio de uma aplicação web que reúne funcionalidades de gestão de estoque, cadastro de doadores, agendamento de doações e monitoramento de bolsas de sangue, além de recursos relacionados à inteligência artificial.

## Funcionalidades

Entre as funcionalidades contempladas no projeto estão:

- **Gestão de estoque:** registro de entradas e saídas de bolsas de sangue e consulta por tipo sanguíneo.
- **Gerenciamento de doadores:** cadastro de doadores e registro de informações relacionadas à sua aptidão para doação.
- **Agendamento de doações:** organização e acompanhamento de agendamentos.
- **Controle de validade e escassez:** monitoramento de bolsas e identificação de situações que exigem atenção.
- **Gestão de unidades de saúde:** cadastro de hospitais e clínicas parceiras.
- **Relatórios e estatísticas:** acompanhamento de informações sobre estoques e doações.
- **Notificações:** recursos para comunicação com doadores e acompanhamento da utilização de bolsas.
- **Inteligência artificial:** funcionalidades planejadas para apoiar a identificação de riscos de escassez e a otimização de campanhas de doação.

A disponibilidade de cada funcionalidade pode variar conforme o estágio de implementação do projeto.

## Arquitetura e desenvolvimento

O projeto é organizado em duas aplicações principais: frontend e backend.

O frontend é desenvolvido com Next.js, React e TypeScript, enquanto o backend utiliza Node.js e Express para disponibilizar uma API REST. A persistência dos dados é realizada em MySQL, com o Prisma ORM como ferramenta de acesso ao banco de dados.

A configuração do projeto contempla Docker Compose para execução dos serviços, migrações de banco de dados e documentação da API com Swagger.

O desenvolvimento foi organizado com a metodologia Scrum, utilizando Sprints para distribuir as atividades e acompanhar a evolução das funcionalidades.
